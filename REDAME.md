
# TaskPy - Gerenciador de Tarefas

Sistema de gerenciamento de tarefas desenvolvido
em Python, com execução pelo terminal.

## Objetivo

Permitir que usuários organizem suas tarefas
de maneira simples e prática.

## Funcionalidades planejadas

- Adicionar tarefas
- Listar tarefas
- Concluir tarefas
- Excluir tarefas
- Salvar tarefas em arquivo JSON

## Tecnologias

- Python
- Git e GitHub
- GitHub Desktop
- Visual Studio Code

## Como executar

1. Instale o Python 3.
2. Abra a pasta do projeto no terminal.
3. Execute o comando `python main.py`.
